# 공기 한 줌의 여정

수도권대기환경청 4개 과의 대표 업무를 **과별 3편, 각 30초** 애니메이션으로 소개하는 정적 웹사이트입니다. 기본 콘텐츠는 기획과의 **SIFT-MS 실시간 이동측정**입니다.

## 업무별 콘텐츠

부서 순서: 기획과 → 대기총량과 → 조사분석과 → 자동차관리과.

| 부서 | 업무 1 | 업무 2 | 업무 3 |
|---|---|---|---|
| 기획과 | SIFT-MS 이동측정 | 미세먼지 계절관리제 | 대기환경 교육·홍보 |
| 대기총량과 | 통합환경관리 | HAPs 비산배출시설 | 사업장 총량관리 |
| 조사분석과 | 굴뚝 시료 채취·분석 | 국가대기오염측정망 | 배출원·배출량 조사 |
| 자동차관리과 | 운행차 배출가스 저감 | 자동차 연료 품질관리 | 도로 재비산먼지 저감 |

나머지 11편(계절관리제·교육홍보·통합환경관리·HAPs·총량관리·측정망·배출원 조사·이동측정 대기질 조사·운행차 저감·연료 품질·도로 재비산먼지)은 SIFT-MS 영상과 같은 야간 네온 톤의 시네마틱 Canvas 애니메이션입니다. 공용 엔진은 `tools/cine/engine.js`, 주제별 장면은 `tools/cine/topics/<id>.js`에 있으며 `node tools/build-cine.js`로 각 HTML을 다시 만듭니다. 각 HTML에 코드·음성·로고를 모두 넣어 내려받은 파일에서도 재생됩니다. 업무·출처 데이터는 `assets/catalog.js` 및 `assets/topics.json`에 있습니다.

## 음성 해설

13편 모두 장면마다 AI 합성 음성(Microsoft 한국어 신경망 음성 ko-KR-SunHiNeural)으로 해설합니다. 영상 아래 ‘음성 해설 듣기’ 버튼으로 켜고 끄며, 켠 상태는 브라우저에 기억됩니다. 메인 화면에서는 부모 창이 소리를 내므로 콘텐츠를 바꿔도 자동재생 차단에 걸리지 않습니다.

- 대본: `tools/voice-script.json` (장면 길이 안에 끝나도록 짧게 작성)
- MP3 생성: `npm i msedge-tts` 후 `node tools/make-voice.mjs` → `assets/voice/<id>-<장면>.mp3`
- 반영: `node tools/build-cine.js` (11편), `node tools/patch-originals.js` (SIFT-MS·굴뚝 시료 2편)
- `tools/cine/shell/`은 빌드·패치 전 페이지 틀이므로 지우지 마세요.

- 메인: `index.html` 또는 `#sift-ms`
- 굴뚝 시료 채취·분석: `index.html#stack`
- 대기총량과 사업장 배출관리: `index.html#emissions`
- 자동차관리과 자동차 배출가스 저감: `index.html#vehicles`
- 개별 화면: `sift-ms.html`, `stack.html`
- 사용자 제공 원본: `originals/` (원본 바이트 보존)

영상은 한 번에 하나만 로드합니다. 장면 선택·일시정지 기능을 제공하며, 콘텐츠 전환 시 새 영상이 시작됩니다. 작은 화면에서는 설명과 장면 버튼이 재배치됩니다. 모든 영상은 30초마다 반복됩니다.

## 부서업무 확인

2026-09-30 수도권대기환경청 공식 홈페이지의 부서업무를 확인했습니다. 각 과의 업무 요약과 해당 공식 페이지 링크는 메인 화면에서 확인할 수 있습니다. 기획과의 SIFT-MS 차량 및 조사분석과의 굴뚝 측정 분류는 사용자 확인을 반영했습니다. 영상은 대표 업무 요약이며 부서의 모든 업무를 포괄하지 않습니다.

기존 두 영상은 원본 장면을 유지하면서 재생 시간을 30초로 조정하고 자막을 단축했습니다. 대기총량과·자동차관리과 영상은 5개 장면(각 4초)으로 제작했습니다. 새 영상의 공유 소스는 `assets/department-player.js`이며, 독립 HTML 다운로드를 위해 각 HTML 안에도 포함했습니다.

## 실행 및 배포

별도 빌드나 패키지 설치가 필요 없습니다. GitHub Pages 설정에서 **Deploy from a branch → main → /(root)** 로 배포할 수 있습니다. 로컬에서는 이 폴더를 정적 HTTP 서버로 열어주세요.

## 출처와 범위

애니메이션은 사용자가 제공한 「공기 한 줌의 여정_-SIFT.html」 및 「공기 한 줌의 여정.html」입니다. `sift-ms.html`과 `stack.html`에는 메인 화면 삽입을 위한 표시·높이 조절 코드를 연결했습니다. SIFT-MS의 장면 선택은 일시정지 상태에서도 전환 효과에 가려지지 않도록 각 장면의 0.6초 시점으로 이동합니다. `originals/` 파일은 변경하지 않았습니다.

기관 로고는 수도권대기환경청 공식 홈페이지의 `https://www.mcee.go.kr/mamo/images/common/logo_new.png`를 사용했습니다. 기관 로고와 사용자 제공 콘텐츠에 일괄적인 오픈소스 라이선스를 부여하지 않습니다.

교육용 예시이며 지도·사업장·농도·측정값은 실제 측정 결과가 아닙니다. Google Fonts 연결은 사용자 제공 원본의 설정을 따릅니다.

## 30초판과 읽기 모드 (2026-09-30)

- 13편 모두 30초로 늘렸습니다. 새 11편은 장면당 6초(`tools/cine/engine.js`의 `SCENE`), SIFT-MS·굴뚝 시료 2편은 재생 속도만 조정했습니다(`tools/patch-originals.js`). 음성은 화면 자막을 거의 그대로 읽도록 다시 만들었습니다.
- `m.html`: 휴대폰용 읽기 모드. 부서·업무를 고르면 장면마다 그림, 큰 글씨 설명, 음성 듣기 버튼이 세로로 나옵니다. ‘처음부터 음성 해설 듣기’는 장면을 차례로 읽으며 화면을 따라 내려갑니다. 메인 화면 상단 ‘휴대폰으로 읽기’ 링크로 연결됩니다.
- 읽기 모드 자료: `node tools/build-mobile.js` → `assets/mobile-scenes.js`. 장면 그림은 `assets/thumbs/<id>-<장면>.jpg`(각 영상의 장면을 캡처한 이미지)입니다. 영상을 고치면 그림도 다시 캡처해야 합니다.
